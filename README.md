## Changes

### Markdown normalization pipeline

Implemented a document post-processing pipeline that transforms raw Markdown files generated by LlamaParse into a strictly structured format suitable for downstream RAG processing.

The normalization stage is performed using a locally hosted Docker Model Runner and is responsible for:

* Normalizing document hierarchy into Markdown headings
* Preserving the original content and numbering
* Generating explicit chunk boundaries using `[chunk_end]` markers
* Producing deterministic and machine-readable document structures

### Qdrant chunk preparation

Implemented a chunk preparation pipeline that converts normalized Markdown documents into structured JSON chunks ready for vectorization and ingestion into Qdrant.

The pipeline includes:

* Extraction of document hierarchy metadata
* Heading path generation
* Chunk hash generation
* Embedding text preparation
* Chunk serialization to JSON
* Generation of Qdrant-ready payload structures

This change establishes the complete preprocessing stage required before embedding generation and vector database indexing.
